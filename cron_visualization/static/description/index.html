Enhanced Cron Visualization gives you a live dashboard of the scheduled actions (cron jobs) of your Odoo instance: which ones are running right now, how long they usually take, when they run next, and how their last runs went.

Key Features:

  • Live kanban dashboard, updated in real time through the Odoo bus whenever a run starts or finishes: no polling, no page refresh.
  • Run history of every execution, manual or automatic: state (success, failed, interrupted, running), duration, the user who started it and the error message.
  • Running indicator and estimated progress bar, based on the average duration of the last 10 successful runs.
  • Next execution countdown on every card, ticking every second.
  • History analysis with list, pivot, graph and calendar views, a "History" smart button on each scheduled action and a "Running" filter.
  • Interrupted runs detected: a run left behind by a worker that died (restart, time limit, out of memory) is flagged as interrupted instead of spinning forever.
  • Automatic cleanup of the history after 90 days, configurable with the cron_visualization.history_retention_days system parameter.
  • Restricted to administrators: the history and the live updates are only available to Settings users.

Usage:

Go to Settings / Technical / Automation / Scheduled Actions (developer mode) and switch to the kanban view. Open a scheduled action to reach its history from the "History" smart button.

Disclaimer:

Please test this module on a staging environment before using it on a production environment, as it inherits methods from the ir.cron model where cron workers are executed.
